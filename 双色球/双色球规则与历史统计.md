# 双色球基础规则与历史统计资料

## 一、游戏规则

- 双色球由中国福利彩票发行管理中心发行，每周二、四、日 21:15 开奖（部分渠道标注 21:30）。
- 投注区分为红球区（1-33 共 33 个号码）与蓝球区（1-16 共 16 个号码）。
- 每注由 6 个红球号码 + 1 个蓝球号码组成，单注金额 2 元。
- 单式投注选择 6+1；复式和胆拖投注按包含的每一注单式投注计。

## 二、奖级与奖金

| 奖级 | 中奖条件（红球+蓝球） | 奖金 |
|------|----------------------|------|
| 一等奖 | 中 6+1 | 浮动：奖池低于1亿时，为当期高奖级奖金的75%（或70%）与奖池累积资金之和，单注封顶500万；奖池高于1亿(含)时按 55%/20%+奖池 拆分，单注封顶500万 |
| 二等奖 | 中 6+0 | 浮动：当期高奖级奖金的25%（或30%），单注封顶500万 |
| 三等奖 | 中 5+1 | 固定 3000 元 |
| 四等奖 | 中 5+0 或 4+1 | 固定 200 元 |
| 五等奖 | 中 4+0 或 3+1 | 固定 10 元 |
| 六等奖 | 中 2+1 或 1+1 或 0+1 | 固定 5 元 |

- 兑奖期限：自开奖之日起 60 个自然日内，逾期未兑奖视为弃奖，弃奖奖金纳入彩票公益金。
- 双色球按当期销售额的约 50% 计提奖金（返奖率约 50%），其余为公益金与发行费等。

## 三、概率基础

- 红球组合数 C(33,6) = 1,107,568
- 含蓝球总组合数 = 1,107,568 × 16 = 17,721,088
- 一等奖概率：1 / 17,721,088 ≈ 0.0000056%
- 六等奖（仅中蓝球即中奖）概率：1/16 ≈ 6.25%
- 各奖级理论中奖概率合计约 6.71%（即每注平均约 6.7% 概率中任意奖级）

### 4.3 形态分布

- 奇偶比：3:3 最多（34 期，34%），2:4 与 4:2 各 22 期（22%），1:5 与 5:1 较少（约 10-11%）。
- 大小比（1-16 小 / 17-33 大）：3:3 最多（41 期，41%），4:2 有 25 期，2:4 有 20 期。
- 和值：均值约 100.8，常见区间 90-140（占 67%），极值 41-153。
- 连号：近 100 期中有 65 期含至少一组连号（66%）。
- 相邻期红球重号：重 1 个最常见（42%），重 2 个 31%，重 0 个 19%，重 3 个 8%。
- 三区分布（1-11 / 12-22 / 23-33）：约 34% / 32% / 34%，基本均衡。

### 4.4 统计结论

- 各号码在长期应趋于均匀分布，短期冷热只是随机波动，不构成预测依据。
- 主流形态（奇偶 3:3、大小 3:3、和值 90-140、含连号）覆盖约 2/3 开奖，可用于筛选"形态合理的组合"以降低偏离度，但不会提高中奖概率。
