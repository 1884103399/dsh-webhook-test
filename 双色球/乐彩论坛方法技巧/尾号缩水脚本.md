# 双色球尾号缩水脚本

来源：https://bbs.17500.cn/thread-13557277-1-1.html

============================================================

尾号缩水 V3.0 (Qt)  使用说明书

============================================================

一、软件简介

------------------------------------------------------------

本工具是一个双色球（中国福利彩票）红球"尾号缩水"分析程序，

Windows 桌面应用。

核心思想：双色球红球全域共有 C(33,6) = 1,107,568 注组合。

把每注红球按升序的第 1~6 位号码取尾数（个位数字），构成

"尾值参数"，分 4 个维度统计与筛选：

4D：任取 4 个位置（15 种位置组合），尾值如 0123

3D：任取 3 个位置（20 种位置组合），尾值如 012

2D：任取 2 个位置（15 种位置组合），尾值如 01

1D：任取 1 个位置（6 种位置组合），尾值如 0

你可以为各位置组合设定允许的尾值参数集合（可叠加和值范围），

程序在全域组合上求交集，输出缩水后的选号号码列表。

【重要声明】本软件仅供个人研究娱乐，彩票开奖完全随机，

任何统计与筛选都不能提高中奖概率，请理性购彩。

二、安装与首次运行

------------------------------------------------------------

本工具是 Python 源码脚本，必须先装好 Python 环境才能运行。

没接触过 Python 的读者请按第 1~4 步照做，全程约 5~10 分钟。

【第 0 步】已经装过 Python 的读者

按 Win+R 输入 cmd 回车，在黑窗口里输入：

python --version

能显示版本号（如 Python 3.12.7）就直接跳到第 2 步；

若提示"不是内部或外部命令"或弹出应用商店，从第 1 步开始。

1. 安装 Python

1) 下载安装包

环境要求：Windows 系统 + Python 3.8 或更高版本。

- 官网下载页：为避免管理删帖，请自行搜索官网地址

选 "Windows installer (64-bit)"，推荐 3.12.x。

- 官网下载慢的话，用国内开源镜像站的安装包列表：

为避免管理删帖，镜像站请自行搜索

里面按版本号分目录（如 3.12.7/），进目录下载

python-3.x.x-amd64.exe 即可。

※ 本项目依赖未锁死版本，pip 会自动挑选与你 Python 匹配

的最新版：Python 3.8 下会装 PySide6 6.6.3.1 + numpy

1.24.3（本机 3.8.5 实测可用），更高版本则装更新的包。

2) 安装（最关键的一步：务必勾选 PATH）

双击安装包，【关键】先勾选窗口最下方的

"Add python.exe to PATH"（Python 3.8 等老版本显示为

"Add Python 3.8 to PATH"），再点 "Install Now"（默认

路径即可）→ 等进度条走完 → 点 Close。

※ 忘了勾会怎样：后面所有 python / pip 命令都提示

"不是内部或外部命令"。补救办法见本节第 6 条。

3) 验证是否装好

按 Win+R 输入 cmd 回车，在黑窗口里依次输入（每行回车）：

python --version

pip --version

两行都能打印版本号（如 Python 3.12.7 / pip 24.0）即成功。

2. 文件清单（解压后放在同一个文件夹内）

- T4D_qt.py         主程序

- t4d_core.py       核心引擎（必须与主程序同目录）

- requirements.txt  依赖清单

- 使用说明书.txt     本说明文件

- fy.ico            （可选）窗口图标，没有也能正常运行

※ 路径建议用纯英文、不带空格，例如 D:\T4D\，可少踩编码坑。

3. 安装依赖（约 1~3 分钟，需要联网）

1) 在该文件夹里打开命令行（最省事的做法）：

打开这个文件夹 → 鼠标点一下上方地址栏（路径会变蓝）→

输入 cmd → 回车。弹出的黑窗口路径就已经是这个文件夹。

2) 在黑窗口里输入下面这行并回车：

pip install -r requirements.txt

requirements.txt 已内置清华 PyPI 镜像源，国内下载较快。

PySide6 体积较大（上百 MB），下载慢属正常，请耐心等待。

- 若中途报超时/网络错误，重试并放宽超时：

pip install --default-timeout=100 -r requirements.txt

- 若提示没有权限（少数公司电脑），改用当前用户安装：

pip install --user -r requirements.txt

4. 启动

在同一个黑窗口里输入并回车：

python T4D_qt.py

首次运行会联网生成数据文件（见第 5 条），程序窗口出现即成功。

以后每次运行都重复这一条命令。

想要双击启动（可选）：在文件夹里新建一个 启动.bat，内容两行：

@echo off

cd /d %~dp0

python T4D_qt.py

以后双击 启动.bat 即可。不要直接双击 T4D_qt.py —— 那样出错时

窗口一闪而过，看不到任何报错信息。

5. 首次运行说明

- 首次运行必须联网，程序会自动下载历史开奖数据、并生成

全部数据文件（保存在程序同目录）。

- 生成理论数量字典需要几十秒，期间控制台会打印

"正在由全域组合生成..."等提示，属正常现象，请耐心等待，

不要当成卡死关闭。

- 建议首次用 python 启动（不要用 pythonw），以便看到

控制台进度提示。

- 数据文件生成后，再次启动即秒开，无需联网。

6. 安装阶段常见报错速查

● 提示 'python' 不是内部或外部命令

→ 安装时没勾 "Add python.exe to PATH"。三选一：

① 重新运行安装包 → 选 Modify → 勾上 "Add Python to

environment variables"（或 Add python.exe to PATH）→

一路 Next 完成；

② 改用 py 启动器（装了 Python 就有，无需 PATH）：

py -3.12 T4D_qt.py

py -m pip install -r requirements.txt

③ 手动加环境变量：把 Python 安装目录（含 python.exe）

和其下的 Scripts 目录加进系统 Path，重开命令行。

● 输入 python 却弹出"微软应用商店"

→ 这是 Windows 的"应用执行别名"在拦截。

设置里搜"应用执行别名"，把 python.exe 和 python3.exe

两项关掉（或直接改用 py 命令）。

● python 能用，但 'pip' 不是内部或外部命令

→ 改用模块方式调用：

python -m pip install -r requirements.txt

● 启动时报 No module named 'PySide6'

→ 依赖没装成功，回到第 3 条重装（务必在程序所在文件夹里

执行 pip install -r requirements.txt）。

● 双击 T4D_qt.py 一闪而过 / 没反应

→ 不要双击运行。必须在黑窗口里执行 python T4D_qt.py，

这样才能看到报错信息。

● 提示找不到文件 / 路径乱码

→ 把整个文件夹移到纯英文路径（如 D:\T4D\）再试。

三、界面布局

------------------------------------------------------------

窗口分左、中、右三栏，中间分隔条可拖拽调整宽度。

【左栏：筛选结果区】

- 大文本框：显示筛选生成的选号号码（每行一注，

形如 01 02 03 04 05 06 + 08）。

文本框宽度固定不变：号码行比框宽时，底部自动出现横向

滚动条（可拖动查看整行），不会把统计表挤窄。

- 底部状态栏：显示筛选耗时、注数、数据更新进度等。

- "筛  选"按钮：按当前全部条件执行全域筛选。

- 文本框右键菜单：全选 / 剪切 / 复制 / 粘贴 / 另存 / 清空。

"另存"保存号码时会自动附带当前的条件设置。

【中栏：统计区】

- 开奖期号下拉框：选择统计截止期号，旁边显示该期开奖号码

（格式：红1..红6 + 蓝球）。

* 默认选中最新一期。

* 选中历史期号时，统计表中"下一期实际命中的尾值参数"

所在行会整行高亮（黄色底），并自动滚动到该位置，

方便回看历史命中情况。

* 选中历史期号时，右栏所有条件输入框会被自动清空

（避免"互锁过滤"把命中行筛掉，保证看到完整表格）。

* 最新一期不高亮（下一期尚未开出）。

- 和值范围：两个输入框，限定 6 个红球之和的上下限

（默认 21 ~ 183，即不限制）。

- 统计表：当前位置组合下，每个尾值参数的历史表现，

共 10 列：

参数        尾值参数（如 0123，保留前导零）

理论数量    全域 1,107,568 注中该参数的理论注数

理论占比    理论数量占全域的百分比

实际数量    历史开奖中实际开出次数

实际占比    实际开出占历史期数的百分比

占比差      理论占比 - 实际占比

最大遗漏    历史上最长连续未开出的期数

当前遗漏    距离最近一次开出的期数

系数(实际)  当前遗漏 x 实际占比

系数(理论)  当前遗漏 x 理论占比

* 缺省按"系数(理论)"列降序排列；点击列头可改按该列

排序（再点一次切换升/降序）。

* 用鼠标选中若干行（可 Ctrl/Shift 多选），表格下方

实时显示"所选参数累计占比 / 数量"。

* 表格右键菜单"参数自动设置"：把选中行的参数一键填入

右栏当前位置组合的输入框。

- 表格下方信息行：显示当前组合的参数总数；存在筛选条件

时，还会显示"互锁后可选项"数量。

【右栏：参数设置区】

页签：4D设置 / 3D设置 / 2D设置 / 1D设置 / 蓝球设置。

前 4 个维度页签结构相同：

- 每行 = 一个位置组合：左侧单选按钮（选中后中栏统计表

即切换到该组合），中间参数输入框（多个参数用空格分隔），

右侧"清"按钮清空该行。

- 输入框悬停提示：显示该组合当前已设置的参数个数。

- "前 [20] 个, 系数>= [0.00]" + "全部" + "自动填充"

（1D 页签无此功能）：

* 不勾"全部"：把统计表排名前 N 的参数填入当前选中的

位置组合。

* 勾选"全部"：对该维度所有位置组合，各取排名前 N 且

系数(实际) >= 设定值的参数自动填入。

注意：系数下限比较的是"系数(实际)"列（当前遗漏 x

实际占比），不是系数(理论)。

- 输入内容变化后约 0.4 秒自动刷新统计表（防抖），

互锁过滤即时生效。

蓝球设置页签（蓝球与红球独立，不参与红球缩水）：

- 结构与红球页签一致：4 行竖向单选按钮，每行一个参数输入框

和一个"清"按钮。单选项决定中栏统计表的口径，输入框填该

口径下的参数：

自然数(16)  输入蓝球号码 01~16，如 08 14；

16 行，理论占比 6.25%

除2余(2)    输入余数 0~1（0=偶数、1=奇数），各 8 个号码，

2 行，理论占比 50%

除4余(4)    输入余数 0~3，各 4 个号码，4 行，25%

除8余(8)    输入余数 0~7，各 2 个号码，8 行，12.5%

鼠标悬停在单选项上会列出该口径每个余数包含哪些号码。

- 各口径条件是"与"关系：可用蓝球号码 = 各口径展开结果的

交集。例：除2余=0 且 除4余=0 -> 可用蓝球 04 08 12 16；

再加 除8余=0 -> 只剩 08 16。全部输入框留空 = 不配蓝球。

- 蓝球参数互锁：某个口径填了条件后，其它口径的统计表只显示

与之兼容的项。例：自然数口径填的全是偶数——除2余只剩

"余0"，除4余只剩"余0/余2"，除8余只剩偶数余数(0/2/4/6)，

绝不会出现奇数。正在看的那个口径仍显示全表（与红球互锁

排除自身组合的做法一致），清空输入即恢复全貌。

互锁只过滤显示行，不改动统计数值。

表格下方显示"总数=XX，互锁后可选项=YY"。

- "前 [4] 个, 系数(实际)>= [0.00]" + "自动填充"：把蓝球统计表

当前排序中"系数(实际) 达标的前 N 项"填进当前选中口径的

输入框（填的是该口径的参数：号码或余数）。

- 统计表右键"参数自动设置"同样把选中项填进当前口径输入框。

- 各口径条件若互相矛盾（交集为空），点"筛  选"会弹窗提示并

中止，不会生成残缺注单。

四、核心功能说明

------------------------------------------------------------

1. 尾号互锁

只要你设置了任何条件（参数或和值范围），统计表就只显示

"与现有条件兼容"的参数——即选它之后全域里仍有注可出的

参数，避免条件组合出 0 注。表格下方会显示

"总数=XXXX，互锁后可选项=XX"。

2. 期号回看与高亮

下拉选择历史期号后，统计范围截止到该期，表格中黄色

高亮行 = 下一期实际开出的尾值参数。可配合列排序观察

命中行的历史分布规律（再次提醒：历史分布不代表未来）。

3. 筛选

设好参数与和值后点"筛  选"，程序在全域 1,107,568 注上

求交集，结果写入左栏。筛选在后台线程执行，界面不会卡死。

各维度、各位置组合之间均为"与"（同时满足）关系。

4. 菜单：文件操作

- 数据更新：联网下载最新开奖数据，并自动增量更新

4 个尾值参数文件。

- 参数导出：把当前全部条件设置保存为 txt

（格式：位置组合=参数 参数 ...）。

- 参数加载：读回以前导出的设置文件。

- 重置条件设置：清空全部参数输入框，和值恢复 21~183。

- 设置统计：在左栏列出当前每个位置组合各设置了多少个

参数，便于检查。

说明：参数导出只写"位置组合=参数"（含蓝球行 蓝球=08 14）；

左栏右键"另存"写的是完整条件段（和值 / 蓝球 / 各维度）。

两种格式"参数加载"都能读回。

5. 蓝球统计与选号组装

蓝球与红球在开奖上相互独立，所以蓝球不参与红球缩水；

它只用于把红球注单组装成完整选号：

最终注数 = 红球注数 × 蓝球个数

输出每行形如：01 02 03 04 05 06 + 08

选定多个蓝球时，同一注红球会分别与每个蓝球组合一次。

6. 蓝球的四种统计口径、互锁与求交

4 个口径各有一个输入框（填该口径的参数），单选项切换中栏

统计表看哪个口径：

自然数(16)  输入号码 01~16             理论占比 6.25%

除2余(2)    输入余数 0~1（偶/奇）       各 50%

除4余(4)    输入余数 0~3                各 25%

除8余(8)    输入余数 0~7                各 12.5%

所有口径的列都与红球统计表一致（理论数量/理论占比/实际

数量/实际占比/占比差/最大遗漏/当前遗漏/系数），默认按

系数(理论)降序，点击列头可换列排序。

求交：各口径条件是"与"关系，可用蓝球 = 各口径展开结果的

交集。例：除2余=0 且 除4余=0 -> 04 08 12 16；再加

除8余=0 -> 只剩 08 16。全部留空 = 不配蓝球（纯红球注单）。

互锁：某个口径填了条件后，其它口径的统计表只显示与之兼容

的项。例：自然数口径填的全是偶数——除2余只剩"余0"、

除4余只剩"余0/余2"、除8余只剩 0/2/4/6，绝不会出现奇数。

正在看的那个口径仍显示全表（与红球互锁排除自身组合一致）。

所以"先定奇偶、再用除4/除8细分"这类逐层收敛的用法是安全的

（互锁只过滤显示行，不改数值）。

若各口径条件组合出空集，点"筛  选"会提示无交集并中止。

五、建议的使用流程

------------------------------------------------------------

1. 先点菜单"数据更新"，确保开奖数据最新。

2. 从低维度往高维度设置条件（1D -> 2D -> 3D -> 4D）：

低维度参数少、统计样本充足，先锁定大方向；再利用互锁

过滤，在高维度上做精细取舍。

3. 配合"自动填充"快速铺底，再手工增删。

4. 随时用"设置统计"检查各组合的参数数量。

5. 需要完整选号号码时，先在"蓝球设置"页挑蓝球（可自动

填充），再点"筛  选"：结果按 红球注数 × 蓝球个数 展开，

每行形如 01 02 03 04 05 06 + 08；左栏右键"另存"保存

结果（自动附带本次全部条件设置，含蓝球）。

七、常见问题

------------------------------------------------------------

Q1：启动报错 "No module named 'PySide6'"？

A1：依赖没装。在程序目录执行 pip install -r requirements.txt。

Q2：首次启动几十秒没反应？

A2：正在生成理论数量字典，属正常现象，控制台有进度提示；

仅限首次，之后秒开。

Q3：点"数据更新"提示失败？

A3：检查网络；数据源为 http://data.17500.cn/ssq_asc.txt，

若该站点临时不可用，稍后再试。

Q4：为什么选中历史期号后我输入的条件被清空了？

A4：这是设计行为：历史期号用于回看"下一期命中"高亮，

若保留条件，互锁过滤会把命中行筛掉、表格不全。

回到最新一期再重新设置条件即可。

Q5：为什么最新一期没有高亮行？

A5：高亮的是"下一期实际开出的参数"，最新一期的下一期

尚未开奖，无数据可标。

Q6：统计表里行数为什么比参数总数少？

A6：你设置了筛选条件，互锁过滤生效，只显示与条件兼容的

参数。清空条件（菜单 - 重置条件设置）即可看到全表。

Q7：能把整个文件夹拷给别人用吗？

A7：可以。只拷 3 个源码文件也行（T4D_qt.py、t4d_core.py、

requirements.txt），对方首次联网运行会自动生成全部

数据文件。

Q8：蓝球页的"互锁后可选项"是什么？

A8：蓝球参数也互锁：其它口径的输入框里填了条件时，当前口径

的统计表只显示与之兼容的项（选了它之后仍有可用蓝球）。

例如自然数口径填的全是偶数，除2余表就只剩"余0"，奇数

那一行不显示。清空蓝球输入即可看到该口径的完整表。

注意：蓝球互锁只做"显示一致性"过滤，不影响红球注数。

Q9：我在蓝球页看不到奇数（或某些行），是被过滤了吗？

A9：是互锁在起作用——你在其它口径里填的条件排除了它。

例：自然数口径填的全是偶数，或 除2余=0。想看到全部项

请清空蓝球输入框；也可用每行的"清"按钮逐个口径清理。

Q10：蓝球四个输入框怎么配合用？

A10：它们是"与"关系：可用蓝球号码 = 各口径展开结果的交集。

例：除2余=0（偶数）+ 除4余=0 -> 04 08 12 16；

再加 除8余=0 -> 只剩 08 16。全部留空 = 不配蓝球。

若组合出空集，点"筛  选"会提示无交集并中止，不会生成

残缺注单。

Q11：蓝球页的"实际占比"之和为什么不正好是 100%？

A11：显示值逐项四舍五入到 4 位小数，行数多时累加会有

±0.5% 以内的误差，属正常（未舍入之和恒为 100%）。

Q12：蓝球留空会怎样？

A12：不做蓝球组装，筛选结果就是纯红球注单（每行 6 个号码），

与旧版行为一致。

Q13：我没装过 Python，具体怎么装？

A13：见"二、安装与首次运行"第 1 条，三步：官网（或华为云镜像）

下载安装包 → 安装时【关键】勾选 "Add python.exe to PATH" →

在黑窗口里用 python --version 验证。安装阶段的各种报错

（不是内部或外部命令、弹出应用商店、pip 找不到）在该章

第 6 条有逐条对应办法。

Q14：安装依赖很慢或失败怎么办？

A14：requirements.txt 已内置清华镜像源。仍失败时：

① 加超时参数重试：

pip install --default-timeout=100 -r requirements.txt

② 提示权限不足就用当前用户安装：

pip install --user -r requirements.txt

③ PySide6 有上百 MB，慢属正常；公司网络有代理的话需先配

代理（pip config set global.proxy http://地址:端口）。

Q15：能不能不装 Python，直接给我个 exe？

A15：本工具目前只提供 Python 源码（不含 exe）。必须装 Python

环境才能运行；装好后可参考第二章第 4 条的"启动.bat"做法

做成双击启动，日常使用与 exe 差别不大。

Q16：装了多个 Python 版本，怎么指定用哪个？

A16：用 py 启动器指定版本，例如：

py -3.12 T4D_qt.py

py -3.12 -m pip install -r requirements.txt
