# ETF / 指数投资实操手册

> 结合约翰·博格指数投资体系 + A股 ETF 实战场景整理。适用对象：个人散户、小资金、零门槛量化。

## 一、核心逻辑：博格三基金组合思想

- 你拥有整个市场（Own the Haystack），不赌单票
- 三件事：① 定股债比例 ② 选低成本宽基 ③ 拿住 + 定期再平衡
- 经典参考：股债比 = 100 - 年龄（40岁→股60/债40），按个人风险承受力调整

## 二、完整流程（A股落地版）

### Step 1 确定资产配置
- 股 / 债 / 商品（黄金）/ 现金 四大类
- 散户参考：宽基指数为主（50%+），黄金≤20%，现金≥10%

### Step 2 选择宽基底仓（场内 ETF）
| 定位 | A股标的 | 说明 |
|---|---|---|
| 核心宽基 | 510300 沪深300 / 563360 中证A500 | 大盘均衡 |
| 成长卫星 | 159915 创业板 / 588000 科创50 | 弹性大，仓位≤20% |
| 债券底仓 | 511010 国债ETF / 511260 | 熊市缓冲 |
| 货币 | 511880 银华日利 / 余额宝 | 现金管理 |

### Step 3 定投纪律（估值分位法）
- 用指数 PE/PB 十年分位定档：<20% 双倍买 / 20-40% 正常买 / 40-60% 半额买 / >60% 停买
- 每月固定日期执行，机械执行不预测
- 双交叉验证：PE 与 PB 分位取更保守档

### Step 4 再平衡
- 每年一次（或偏离目标±5%时触发）
- 卖出超配、买入低配，纪律化执行

## 三、常见错误（A股散户特供）

1. 把行业主题 ETF 当底仓 —— 单行业是赌注，不是配置（已踩坑：5只行业ETF策略回测过拟合）
2. 低估费率差异 —— 主动 1.8%/年 vs 指数 0.2%/年，10万本金一年差 1600 元
3. 场内小单频繁交易 —— 佣金最低 5 元/笔，1000 元来回 1% 成本，单笔至少 5000+
4. 估值高位追涨 —— PE 分位 >60% 停买，管住手
5. 黄金单仓过重 —— 单一资产 ≤25%，贵金属合计 ≤30%

## 四、进阶技巧

- 场内 ETF 与场外联接 C 可互相替代：场内费率低但受最低佣金约束；场外 C 类免交易费但年费率 0.8% 左右
- 定投 + 止盈结合：浮盈 20% 卖 1/3、40% 再卖 1/3、分位 >80% 清仓；止损 -15% 走人
- 多框架复核：规则引擎（估值分位）+ AI 信号并行，不单依赖一个信号
- 折溢价：场内买卖注意溢价率，溢价>1% 时考虑场外申赎替代

## 五、自检清单（每次买入前过一遍）

- [ ] 这是宽基还是行业主题？（行业主题仓位 ≤20%）
- [ ] 当前 PE/PB 分位多少？（>60% 停买）
- [ ] 单笔金额场内 ≥5000 元？
- [ ] 买入后计划持有多久？（<7天不碰 C 类/场内）
- [ ] 该资产占比是否超过目标 5%？（超过则再平衡而非加仓）
